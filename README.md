### // about

I'm a software engineer based in **Egypt**, focused on the frontend. I care about
clean component architecture, sensible state management, and UI that stays fast as it
grows. Most of my work lives in the **React / TypeScript / Tailwind** ecosystem, and I
enjoy the occasional detour into AI and tooling projects.

When I'm not shipping UI, I'm solving problems on **Codeforces** and **Codewars** —
it keeps me sharp on the fundamentals.
